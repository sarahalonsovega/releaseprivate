# CUELUM website — design rules

## Text alignment

Every section/block follows exactly one of these two patterns. Never mix them within a single block.

1. **Centered** — headline, body copy, labels, and list items in the block are all center-aligned. This is the default for single-column sections (hero statements, standalone quotes, centered card grids like VEXA Services or Curiosity's "Why breadth holds up").
2. **Split / asymmetric layouts** — when a block has a genuine left/right composition (numbered list + image panel, asymmetric two-column split like VEXA's "Three Forces" or Curiosity's Methodology), the headline and its accompanying body copy align to the *same* side within their column. Left column content is left-aligned top to bottom; right column content (if text) is likewise consistent. Never center a headline over left-aligned body text, or vice versa, within the same block.

Pick alignment per block, not per element. If a section doesn't clearly call for a split composition, default to centered rather than left-aligning "because it reads more editorial."
